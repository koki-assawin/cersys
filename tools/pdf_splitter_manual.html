คู่มือโปรแกรมแยกไฟล์ PDF

PDF Splitter สำหรับเตรียมไฟล์เกียรติบัตรก่อนนำเข้าระบบดาวน์โหลดเกียรติบัตรออนไลน์

1. โปรแกรมนี้ใช้ทำอะไร

ใช้แยกไฟล์ PDF ไฟล์ใหญ่ที่มีเกียรติบัตรหลายใบรวมกัน (เช่น พิมพ์จากจดหมายเวียนออกมาเป็นไฟล์เดียว 300 หน้า) ให้เป็นไฟล์ย่อยคนละไฟล์ ตั้งชื่อตามลำดับ 1.pdf, 2.pdf, 3.pdf … อัตโนมัติ แล้วดาวน์โหลดออกมาเป็นไฟล์ .zip

ขั้นตอนทั้งหมดตั้งแต่ต้นจนผู้รับดาวน์โหลดได้:

PDF รวมทุกใบ→ แยกไฟล์ด้วยโปรแกรมนี้→ อัปโหลดขึ้น Google Drive→ สร้าง URL อัตโนมัติด้วย Google Sheet→ เพิ่มกิจกรรมในหน้า Admin
โปรแกรมทำงานบนเครื่องของคุณเท่านั้น ไฟล์ไม่ถูกส่งขึ้นอินเทอร์เน็ต (ต้องใช้อินเทอร์เน็ตเฉพาะตอนติดตั้งครั้งแรก)

2. ติดตั้งโปรแกรม (ทำครั้งเดียวต่อเครื่อง)

  1. ดาวน์โหลดไฟล์ PDF_Splitter.zip จากหน้า Admin เมนู เครื่องมือแยกไฟล์ PDF
  2. คลิกขวาที่ไฟล์ zip → Extract All… (แตกไฟล์) ไว้ที่ไหนก็ได้ เช่น Desktop หรือ D:\PDF_Splitter
  3. เปิดโฟลเดอร์ที่แตกออกมา ดับเบิลคลิก 1_ติดตั้ง.bat (ต้องต่ออินเทอร์เน็ต)
  4. รอจนขึ้นข้อความ [OK] ติดตั้งเสร็จเรียบร้อย แล้วกดปุ่มใดก็ได้เพื่อปิด

ถ้าขึ้นว่า “ไม่พบ Python ในเครื่องนี้”

  1. โปรแกรมจะเปิดหน้าเว็บ python.org ให้ กด Download Python (เวอร์ชัน 3.10 ขึ้นไป)
  2. เปิดไฟล์ที่ดาวน์โหลดมา ติ๊กช่อง “Add Python to PATH” ด้านล่างก่อน แล้วกด Install Now
  3. ติดตั้งเสร็จแล้ว ดับเบิลคลิก 1_ติดตั้ง.bat อีกครั้ง
Windows อาจเตือน “Windows protected your PC” ตอนเปิดไฟล์ .bat ครั้งแรก ให้กด More info → Run anyway

3. เปิดโปรแกรม

  1. ดับเบิลคลิก 2_เปิดโปรแกรม.bat
  2. จะมีหน้าต่างสีดำขึ้นมา และเบราว์เซอร์จะเปิดหน้า http://localhost:5000 ให้อัตโนมัติ (ถ้าไม่เปิด ให้พิมพ์ที่อยู่นี้ในเบราว์เซอร์เอง)
ห้ามปิดหน้าต่างสีดำระหว่างใช้งาน ถ้าปิด โปรแกรมจะหยุดทำงานทันที ใช้เสร็จแล้วจึงปิดได้

4. วิธีแยกไฟล์

  1. เลือกไฟล์ คลิกที่กรอบ Click or drag PDF file here หรือลากไฟล์ PDF มาวาง (ขนาดไม่เกิน 100 MB) โปรแกรมจะแสดงจำนวนหน้าและขนาดไฟล์
  2. เลือกวิธีแยก ที่ Split Method
    ตัวเลือกใช้เมื่อตั้งค่า
    By Number of Parts
    แยกตามจำนวนส่วน    		 เกียรติบัตร 1 ใบ = 1 หน้า (กรณีปกติ) ใส่ Number of Parts = จำนวนหน้าทั้งหมด จะได้ 1 ไฟล์ต่อ 1 หน้า
    ถ้าใบละ 2 หน้า ให้ใส่จำนวนหน้า ÷ 2
    By Max Size
    แยกตามขนาดไฟล์    		 ต้องการให้แต่ละไฟล์ไม่เกินขนาดที่กำหนด เช่น เพื่อแนบอีเมล ใส่ Max Size per Part (MB)
  3. ตั้งชื่อไฟล์ ที่ File Naming
    • 1.pdf, 2.pdf, 3.pdf … ใช้แบบนี้สำหรับระบบเกียรติบัตร ชื่อไฟล์จะตรงกับคอลัมน์ “ลำดับที่” และสคริปต์สร้าง URL อัตโนมัติในขั้นตอนที่ 6 ต้องใช้ชื่อไฟล์แบบนี้
    • filename_part1.pdf … ใช้ชื่อไฟล์เดิมต่อด้วยเลขส่วน
    • Custom prefix ตั้งคำนำหน้าเอง เช่น doc_ → doc_1.pdf
  4. เลขเริ่มต้น ที่ Start Number ปกติใส่ 1 ถ้าแยกต่อจากชุดก่อน เช่น ชุดแรกมี 80 ใบ ชุดที่สองให้ใส่ 81 จะได้ 81.pdf, 82.pdf …
  5. ตรวจรายชื่อไฟล์ที่จะได้ในช่อง Preview แล้วกด Split PDF
  6. เบราว์เซอร์จะดาวน์โหลดไฟล์ ชื่อไฟล์_split.zip แตกไฟล์ออกมาจะได้ PDF ทีละใบ

5. อัปโหลดไฟล์ขึ้น Google Drive

  1. เข้า drive.google.com สร้างโฟลเดอร์ใหม่ 1 โฟลเดอร์ต่อ 1 กิจกรรม เช่น เกียรติบัตร_อบรม_2569
  2. เปิดโฟลเดอร์นั้น แล้วลากไฟล์ PDF ทั้งหมดที่แยกไว้ (1.pdf, 2.pdf …) มาวาง รอจนอัปโหลดครบทุกไฟล์
  3. คลิกขวาที่โฟลเดอร์ → แชร์ → ตรง “การเข้าถึงทั่วไป” เลือก ทุกคนที่มีลิงก์ (Anyone with the link) สิทธิ์ ผู้มีสิทธิ์อ่าน (Viewer) → เสร็จสิ้น
    ไฟล์ทุกไฟล์ในโฟลเดอร์จะได้สิทธิ์นี้ตามไปด้วย ผู้รับจึงเปิดเกียรติบัตรของตัวเองได้
  4. คัดลอก ID ของโฟลเดอร์ เก็บไว้ใช้ในขั้นตอนที่ 6 ดูได้จากแถบที่อยู่ของเบราว์เซอร์ขณะเปิดโฟลเดอร์ เป็นข้อความหลัง /folders/
    ตัวอย่าง: https://drive.google.com/drive/folders/1M-aXTYRq_XHAi0gGoNXOk_6pRZpXTtTD → ID คือ 1M-aXTYRq_XHAi0gGoNXOk_6pRZpXTtTD
ในโฟลเดอร์ควรมีเฉพาะไฟล์ PDF ของกิจกรรมนี้เท่านั้น ห้ามมีไฟล์ชื่อซ้ำกัน และชื่อไฟล์ต้องเป็นตัวเลขล้วน เช่น 1.pdf (ถ้าชื่อไฟล์มีตัวเลขอื่นปน เช่น 2569_1.pdf ระบบจะอ่านเลขผิดเป็น 25691)

6. สร้าง Google Sheet และใส่ URL อัตโนมัติ

ใช้แบบฟอร์ม Google Sheet ที่มีสคริปต์ (Apps Script) สำหรับดึงลิงก์ของไฟล์ PDF ทุกไฟล์ในโฟลเดอร์มาใส่ในคอลัมน์ URL ให้อัตโนมัติ ไม่ต้องคัดลอกลิงก์ทีละไฟล์

6.1 ทำสำเนาแบบฟอร์ม

  1. เปิดลิงก์ทำสำเนาแบบฟอร์ม (ล็อกอินบัญชี Google ก่อน):
    https://docs.google.com/spreadsheets/d/15TY0glWWc6Q67P98jfBySdb8Oy8sPnjO9hK_1dLNiyM/copy
  2. กด ทำสำเนา (Make a copy) แล้วตั้งชื่อไฟล์ตามกิจกรรม เช่น รายชื่อ_อบรม_2569
    สำเนาจะเป็นของคุณเอง แก้ไขได้ และสคริปต์จะติดมาด้วย

6.2 กรอกลำดับที่และชื่อ-สกุล

กรอกตั้งแต่แถวที่ 2 ลงไป เว้นคอลัมน์ C (URL) ว่างไว้ สคริปต์จะกรอกให้ ห้ามแก้ชื่อหัวคอลัมน์ในแถวที่ 1

A: ลำดับที่B: ชื่อ-สกุลC: URLไฟล์ที่ตรงกัน
1นายสมชาย ใจดี(เว้นว่าง)1.pdf
2นางสาวสมหญิง รักดี(เว้นว่าง)2.pdf
3นายทดสอบ ระบบ(เว้นว่าง)3.pdf
สำคัญที่สุด: ลำดับที่ต้องตรงกับไฟล์ คือ 1.pdf ต้องเป็นเกียรติบัตรของคนที่มีลำดับที่ 1 ถ้าลำดับรายชื่อไม่ตรงกับลำดับหน้าใน PDF ต้นฉบับ ผู้รับจะได้เกียรติบัตรของคนอื่น แนะนำให้คัดลอกรายชื่อจากไฟล์เดียวกับที่ใช้ทำจดหมายเวียนเกียรติบัตร

6.3 ใส่ ID โฟลเดอร์ในสคริปต์

  1. ใน Google Sheet ไปที่เมนู ส่วนขยาย (Extensions) → Apps Script
  2. หาบรรทัดที่ 3 var folderId = "...."; แล้ว แทนที่ข้อความในเครื่องหมายคำพูด ด้วย ID โฟลเดอร์จากขั้นตอนที่ 5 ข้อ 4 (เครื่องหมาย " ทั้งสองข้างต้องอยู่ครบ) 
    var folderId = "ใส่ ID โฟลเดอร์ของคุณตรงนี้";
  3. กด บันทึก (ไอคอนแผ่นดิสก์ หรือ Ctrl+S)

6.4 เรียกใช้สคริปต์

  1. ตรวจว่าช่องเลือกฟังก์ชันด้านบนเป็น generatePdfUrls แล้วกด ▷ เรียกใช้ (Run)
  2. ครั้งแรกต้องให้สิทธิ์ (ทำครั้งเดียวต่อสำเนา):
    1. กด ตรวจสอบสิทธิ์ (Review permissions) แล้วเลือกบัญชี Google ของคุณ
    2. ถ้าขึ้นว่า Google ยังไม่ได้ยืนยันแอปนี้ ให้กด ขั้นสูง (Advanced) → ไปที่ … (ไม่ปลอดภัย)
      เป็นเรื่องปกติของสคริปต์ที่เราสร้างเอง สคริปต์นี้แค่อ่านรายชื่อไฟล์ในโฟลเดอร์และเขียนลิงก์ลง Sheet ของคุณเท่านั้น
    3. กด อนุญาต (Allow)
  3. รอจนในส่วน บันทึกการดำเนินการ ขึ้น การดำเนินการเสร็จสมบูรณ์ (ไฟล์หลักร้อยใช้เวลาประมาณ 1–2 นาที) ที่หน้า Google Sheet จะขึ้นกล่อง “สร้าง URL เรียบร้อยแล้ว!”
  4. กลับไปที่ Google Sheet ตรวจว่าคอลัมน์ C มีลิงก์ครบทุกแถว แล้วคลิกลิงก์สุ่ม 2–3 แถว ดูว่าชื่อในเกียรติบัตรตรงกับชื่อในแถวนั้น
โค้ดสคริปต์ทั้งหมด (ใช้เมื่อเปิด Apps Script แล้วไม่มีโค้ด ให้คัดลอกไปวางแทนของเดิมทั้งหมด) 
function generatePdfUrls() {
  // 1. ระบุ ID ของโฟลเดอร์ Google Drive และ Sheet
  var folderId = "ใส่ ID โฟลเดอร์ของคุณตรงนี้";
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("ชีต1"); // ชื่อชีตของคุณ

  // 2. ดึงข้อมูลจากชีต (คอลัมน์ ลำดับ)
  var data = sheet.getDataRange().getValues();

  // 3. เข้าถึงโฟลเดอร์ใน Drive
  var folder = DriveApp.getFolderById(folderId);
  var files = folder.getFilesByType(MimeType.PDF);

  // 4. วนลูปอ่านไฟล์ PDF ทั้งหมดในโฟลเดอร์
  while (files.hasNext()) {
    var file = files.next();
    var fileName = file.getName(); // เช่น "1.pdf"
    var fileUrl = file.getUrl();

    // ดึงเฉพาะตัวเลขจากชื่อไฟล์ เช่น "1.pdf" -> "1"
    var fileNumber = fileName.replace(/[^0-9]/g, "");

    // 5. ค้นหาแถวใน Sheet ที่ "ลำดับ" ตรงกับ "เลขไฟล์"
    for (var i = 1; i < data.length; i++) { // เริ่มที่ 1 เพื่อข้ามหัวตาราง
      var rowOrder = data[i][0].toString(); // คอลัมน์ A (ลำดับ)

      if (rowOrder === fileNumber) {
        // บันทึก URL ลงในคอลัมน์ C (URL) แถวที่ i+1
        sheet.getRange(i + 1, 3).setValue(fileUrl);
        break;
      }
    }
  }
  Browser.msgBox("สร้าง URL เรียบร้อยแล้ว!");
}

7. เพิ่มกิจกรรมในระบบเกียรติบัตร

  1. ใน Google Sheet กด แชร์ → “การเข้าถึงทั่วไป” เลือก ทุกคนที่มีลิงก์ สิทธิ์ ผู้มีสิทธิ์อ่าน → คัดลอกลิงก์
  2. เข้าหน้า Admin เมนู เพิ่มกิจกรรมใหม่ กรอกชื่อกิจกรรม แล้ววางลิงก์ Google Sheet
  3. กด ทดสอบอ่าน Google Sheet ตรวจว่าจำนวนรายการถูกต้อง แล้วกด สร้างกิจกรรม
  4. ทดลองค้นหาชื่อตัวเองในหน้าผู้ใช้ และเปิดเกียรติบัตรดูอีกครั้ง
ถ้าภายหลังแก้ไขรายชื่อหรือ URL ใน Google Sheet ให้ไปที่เมนู จัดการกิจกรรม → แก้ไข → ติ๊ก โหลดรายชื่อจาก Google Sheet ใหม่ → บันทึก
