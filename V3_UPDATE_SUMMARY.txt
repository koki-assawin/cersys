================================================================
  ระบบ V3.0 - ใช้ Google Sheet แทน Excel
================================================================

✅ การเปลี่ยนแปลงหลัก:

1. ไม่ต้องอัพโหลดไฟล์ Excel
   - Before: อัพโหลด Excel ผ่านระบบ
   - After:  ใส่ลิงค์ Google Sheet

2. คุณเตรียม URL เอง
   - Before: ระบบสร้าง URL จาก File ID
   - After:  คุณใส่ URL ใน Google Sheet

3. แก้ไขได้ทันที
   - Before: แก้ไขต้องอัพโหลดใหม่
   - After:  แก้ Google Sheet ได้เลย

================================================================

📝 โครงสร้าง Google Sheet:

คอลัมน์ที่ 1: ลำดับที่
คอลัมน์ที่ 2: ชื่อ-สกุล
คอลัมน์ที่ 3: URL

ตัวอย่าง:
| ลำดับที่ | ชื่อ-สกุล | URL |
|---------|----------|-----|
| 1 | นายสมชาย ใจดี | https://drive.google.com/file/d/... |
| 2 | นางสาวสมหญิง รักดี | https://drive.google.com/file/d/... |

================================================================

🚀 วิธีใช้งาน:

ADMIN:

1. สร้าง Google Sheet ใหม่
   - เข้า Google Drive
   - New → Google Sheets → Blank
   - สร้างคอลัมน์: ลำดับที่, ชื่อ-สกุล, URL
   - กรอกข้อมูล

2. แชร์ Google Sheet
   - Share → Anyone with the link can VIEW
   - Copy link

3. เพิ่มกิจกรรมในระบบ
   - run_admin.bat
   - Login: admin / admin123
   - เมนู: เพิ่มกิจกรรมใหม่
   - วาง URL ของ Google Sheet
   - คลิก "ทดสอบอ่าน Google Sheet"
   - สร้างกิจกรรม

USER:
   - run_user.bat
   - เลือกกิจกรรม
   - ค้นหาชื่อ
   - ดาวน์โหลดหรือดูไฟล์

⚠️ สิ่งที่ต้องระวัง:

1. ชื่อคอลัมน์ต้องเป็น: ลำดับที่, ชื่อ-สกุล, URL
   (ตัวพิมพ์ต้องตรงทุกตัว)

2. Google Sheet ต้องแชร์เป็น "Anyone with the link can VIEW"

3. URL ต้องเป็น URL ของ Google Sheet
   (ไม่ใช่ folder link)

4. แก้ Google Sheet แล้วต้องสร้างกิจกรรมใหม่
   (ข้อมูลเก่าใน database ไม่อัพเดทอัตโนมัติ)
