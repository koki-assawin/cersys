  ขั้นตอนต่อไป - อัพเดทฐานข้อมูล Supabase เป็น V2.0
===============================================================

✅ Dependencies ติดตั้งเรียบร้อยแล้ว!

📋 ตอนนี้คุณต้องทำ:

1. เปิด Supabase Dashboard
   ----------------------------------------
   URL: https://supabase.com/dashboard

2. เลือก Project ของคุณ

3. ไปที่ SQL Editor (เมนูด้านซ้าย)

4. คลิก "New Query"

5. เปิดไฟล์นี้: setup_database_v2.sql
   ----------------------------------------
   ตำแหน่ง: C:\xampp\htdocs\cersys\setup_database_v2.sql

6. คัดลอก SQL ทั้งหมด → วางใน SQL Editor

7. คลิก "Run" (หรือกด Ctrl+Enter)

8. รอจนเห็นข้อความ Success

9. กลับมารันคำสั่งนี้เพื่อทดสอบ:
   ----------------------------------------
   run_test_v2.bat

   หรือ

   py test_v2_connection.py

===============================================================

หากทดสอบผ่าน คุณจะได้:

- ✓ Admin user (username: admin, password: admin123)

- ✓ ตาราง certificates พร้อม order_number
- ✓ ระบบพร้อมใช้งาน!

จากนั้นสามารถรันระบบ:
